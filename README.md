# Portfólio — JC Chihueno

Portfólio pessoal, documentando minha transição de designer gráfico para desenvolvedor fullstack — um espaço que cresce junto com meu aprendizado, reunindo tanto projetos de design quanto de programação.

🔗 **Acesse:** [jcchihueno.vercel.app](https://jcchihueno.vercel.app)

## Sobre o projeto

Diferente de um portfólio estático, este site foi construído para ser atualizado continuamente: novos projetos, certificados e o currículo são adicionados sem necessidade de alterar o código, através de um painel de dados conectado diretamente ao site.

## Tecnologias

- **React** + **Vite** — base da aplicação
- **Tailwind CSS** — estilização
- **Framer Motion** — animações e transições
- **Three.js** — efeito de fundo em 3D
- **Firebase (Firestore)** — projetos, certificados e comentários, gerenciados dinamicamente
- **Cloudinary** — hospedagem de imagens e documentos

## Funcionalidades

- Separação entre projetos de **Design** e de **Código**, cada um com sua própria forma de apresentação
- Seção de certificados
- Comentários públicos
- Totalmente em português
